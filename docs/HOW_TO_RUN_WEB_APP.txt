================================================================================
          HOW TO RUN THE WEB APPLICATION - STEP BY STEP GUIDE
================================================================================

This guide provides detailed instructions for launching and using the Heart
Disease Prediction System web application.

================================================================================
PREREQUISITES
================================================================================

Before running the web application, ensure:

1. ✓ Python 3.8+ is installed
2. ✓ All dependencies are installed (pip install -r requirements.txt)
3. ✓ Models have been trained (python main.py has been executed)
4. ✓ All output files are generated in outputs/ and models/ directories

If you haven't completed the training step, run:
   python main.py

This will train all models and generate necessary files (~2-5 minutes)

================================================================================
LAUNCHING THE WEB APPLICATION
================================================================================

METHOD 1: Using Command Line
-----------------------------

1. Open Terminal/Command Prompt

2. Navigate to project directory:
   cd c:\Users\adepu\Downloads\RAA

3. Activate virtual environment (if using):
   Windows: .venv\Scripts\activate
   macOS/Linux: source .venv/bin/activate

4. Run Streamlit:
   streamlit run app.py

5. The application will automatically open in your default browser
   Default URL: http://localhost:8501

6. If browser doesn't open automatically, manually navigate to:
   http://localhost:8501


METHOD 2: Using VS Code
-----------------------

1. Open the project in VS Code

2. Open Terminal in VS Code (Ctrl + `)

3. Run:
   streamlit run app.py

4. Click the local URL that appears in the terminal


METHOD 3: Custom Port
---------------------

If port 8501 is already in use:

   streamlit run app.py --server.port 8502

Replace 8502 with any available port

================================================================================
USING THE WEB APPLICATION
================================================================================

OVERVIEW OF INTERFACE
---------------------

The application has 3 main tabs:

1. 🏥 PREDICTION TAB - Make predictions
2. 📊 MODEL PERFORMANCE TAB - View model statistics
3. 📖 DOCUMENTATION TAB - Read about the system


TAB 1: PREDICTION
-----------------

Step-by-Step Process:

1. Navigate to the "Prediction" tab (should be open by default)

2. Enter Patient Information in the SIDEBAR (left panel):
   
   Demographics:
   - Age: Patient's age in years (18-100)
   
   Clinical Measurements:
   - Various medical parameters
   - Blood pressure readings
   - Lab test results
   - ECG measurements
   - etc.

3. Review entered values to ensure accuracy

4. Click the "🔮 Predict Heart Disease" button (large blue button)

5. Wait for analysis (takes 1-2 seconds)

6. View Results:
   
   GREEN BOX: ✅ NO HEART DISEASE DETECTED
   - Patient appears to be at low risk
   - Continue healthy lifestyle
   - Regular check-ups recommended
   
   RED BOX: ⚠️ HEART DISEASE DETECTED
   - Patient appears to be at high risk
   - Immediate consultation with healthcare professional advised
   - This is a prediction, not a diagnosis

7. Review Prediction Confidence:
   - See probability percentages
   - View bar chart visualization
   - Higher confidence = more certain prediction

8. Take Appropriate Action:
   - Follow medical recommendations
   - Consult with doctor
   - Do not rely solely on this prediction


TAB 2: MODEL PERFORMANCE
------------------------

This tab displays:

1. Performance Metrics Table:
   - Accuracy, Precision, Recall, F1-Score, ROC-AUC
   - For all 7 models
   - On both full and selected features

2. ROC Curves:
   - Visual representation of model performance
   - Shows trade-off between true/false positive rates
   - Higher curve = better performance

3. Confusion Matrices:
   - Shows prediction accuracy breakdown
   - True Positives, True Negatives
   - False Positives, False Negatives

4. Performance Comparison:
   - Bar charts comparing all models
   - Across all metrics
   - Easy visual comparison

5. Feature Importance:
   - Top 30 most important features
   - Helps understand what drives predictions


TAB 3: DOCUMENTATION
--------------------

Contains:
- System overview
- Methodology explanation
- Dataset information
- Model descriptions
- Medical disclaimer
- References
- Credits


SIDEBAR FEATURES
----------------

The sidebar (left panel) includes:

1. Patient Information Input Form:
   - All medical parameters
   - Numeric input fields
   - Reasonable default values
   - Value validation

2. About Section:
   - System information
   - Model details
   - Accuracy metrics
   - Medical disclaimer

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: App won't start
SOLUTION:
   1. Check if models are trained: python main.py
   2. Verify dependencies: pip install -r requirements.txt
   3. Check Python version: python --version (should be 3.8+)

PROBLEM: "Models not found" error
SOLUTION:
   Run training first: python main.py
   This creates all necessary model files

PROBLEM: Port already in use
SOLUTION:
   Use different port: streamlit run app.py --server.port 8502

PROBLEM: Slow performance
SOLUTION:
   1. Close other applications
   2. Restart the app
   3. Clear browser cache

PROBLEM: Prediction button doesn't work
SOLUTION:
   1. Refresh the page (F5)
   2. Check browser console for errors
   3. Restart the app

PROBLEM: Visualizations not loading
SOLUTION:
   1. Check if output files exist in outputs/
   2. Re-run main.py to regenerate
   3. Refresh browser

PROBLEM: Values won't save
SOLUTION:
   1. Enter values and click outside the field
   2. Ensure values are within allowed ranges
   3. Check for validation errors

================================================================================
STOPPING THE APPLICATION
================================================================================

To stop the web application:

METHOD 1: Using Terminal
   Press Ctrl + C in the terminal where Streamlit is running

METHOD 2: Close Terminal
   Simply close the terminal/command prompt window

METHOD 3: Using Streamlit Menu
   Click the hamburger menu (☰) → Settings → Stop

The app will stop and the local server will shut down.

To restart: streamlit run app.py

================================================================================
ACCESSING FROM OTHER DEVICES (OPTIONAL)
================================================================================

To access the app from other devices on your network:

1. Find your computer's IP address:
   Windows: ipconfig
   macOS/Linux: ifconfig

2. Start app with network access:
   streamlit run app.py --server.address=0.0.0.0

3. Access from other devices using:
   http://YOUR_IP_ADDRESS:8501
   
   Example: http://192.168.1.100:8501

4. Ensure firewall allows connections on port 8501

⚠️ Security Warning: Only do this on trusted networks
